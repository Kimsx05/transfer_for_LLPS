# Fixed analysis plan; seed 123

Original 20 evaluation patients are globally reserved: no cells/specimens of these patients may enter newly trained or calibrated models or signature selection. Historical predictions are reused as a benchmark; new references have stricter exclusions, so the historical and refitted baseline are labelled separately. Already observed evaluation results are development/evaluation, NOT a new blind test. Additional cross-dataset extrapolation uses training patients from other datasets only, always excluding the reserved 20. No clinical outcomes are loaded during selection.

Bounded model candidates: (1) refitted baseline MuSiC, >=20 cells/patient/type and >=3 training patients/type; (2) optimized reference MuSiC, >=5 cells/patient/type, >=3 patients/type, equal-dataset means, protein-coding shared-platform genes excluding mitochondrial/ribosomal genes, and training-only type-vs-dataset informative genes (top 100/type); (3) custom two-level MuSiC using the same optimized reference: major stromal-vs-other fit, subtraction of nonstromal fitted RNA on the original linear scale, within-stromal fit, then multiply within-stromal fractions by parent cell fraction. Native music_prop.cluster is inspected; the saved implementation uses incompatible fine-design/coarse-coefficient dimensions for this 14-to-8 layout, so the custom procedure is explicit and not labelled native MuSiC.

Main comparison uses the same original 20 patients without excluding errors/outliers, records every failed prediction, reports common evaluable sets and coverage separately. Minimum cell threshold relaxation is a reference change, never a validation-patient filter. C6 is never deleted, merged, or removed from the denominator. Cross-dataset unsupported folds remain unsupported.

Method selection considers dataset-adjusted rank association, calibration errors and dataset-specific bias, patient-type discrimination and platform transfer. Reference uses UMI/cell size factors, so estimated coefficients are model-based cell fractions, while multiplication by size factors yields RNA contributions. Neither estimates absolute tissue cell counts. No post-hoc calibration on evaluation patients. Use prior operational calibration thresholds as reference (rho>=.7, MAE<=.15, RMSE<=.20), plus within-dataset coherence and real-platform compatibility; do not treat a single threshold as definitive proof.

If no robustly transferable abundance reference results, construct ONE identity signature from the nonreserved training pool. Original DEG lists annotate candidates but cannot select them because they used evaluated patients. Fixed training-only criteria: C0 >=5 CPM, >2-fold mean relative expression vs each other type, >=70% available patient C0-vs-other paired directions positive, positive C0 contrast in >=2 datasets. Rank by worst-other-type log2 fold change; cap 20 genes. Exclude COL*/FN1 and Hallmark inflammatory/hypoxia/TNF genes from identity selection; list these separately as state genes. Use a fixed shared-platform protein-coding gene universe and single-sample normalized mean ranks, not abundance. Validate on reserved cell-type profiles and mixtures, including association with total stromal content. Operational identity screen: held-out C0-vs-other stroma AUC>=.75, median paired C0-minus-C5 score>0, and positive mixture association without sign reversal across adequately sampled datasets. If inadequate, do not manufacture clinical results.

Clinical design, if an estimand passes: primary tumors only; preserve AJCC/pT/cT distinctions; fixed cohort-specific median cutoff (computed among valid OS cases), low<=median/high>median; all non-significant results retained. OS log-rank, binary and continuous per-SD Cox, proportional-hazards test; age+stage adjustment with grade only if not sparse/collinear and events adequate. No purity values fabricated. Cohort-specific models; forest descriptive unless assumptions warrant pooling. Signature route filenames and labels explicitly say C0-like signature score. Cohort outcome fields cannot affect method/gene selection.
