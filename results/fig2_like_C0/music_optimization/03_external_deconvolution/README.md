# External estimand decision

No abundance-based bulk coefficients were generated. The optimized reference improved developmental ranking but retained dataset-dependent calibration bias and an unsupported held-out dataset. RNA-seq-to-microarray abundance transfer was not established. See ../02_model_comparison/method_decision.md.

The authorized fallback was completed. Per-sample clinical metadata and **C0-like signature scores** are in ../06_signature_fallback/*_signature_clinical.tsv. These scores have no estimated C0–C6 cell fractions; filling such columns would falsely imply deconvolution.

Formal clinical figures are ../04_stage/Fig2E_signature_* and ../05_survival/Fig2F_signature_*. They are expression-based exploratory analyses, not abundance validation.
