# Execution notes

- All source objects and historical result paths are read-only. Main computations use one BLAS/OpenMP/R thread and CPU affinity restricted to the same four CPUs. Random programs 21–30 and 31–50 were completed by two independent single-thread R workers while the main process evaluated earlier random programs; no nested parallelism. The serial `run_all.sh` reproduces the same frozen random gene lists and can reuse checkpoints.
- Initial audit assertion requiring all gene IDs to be symbols was corrected after identifying 366/414 ENSG rows. These finite tested genes remain in their actual ranking positions; no guessed ID conversion or imputation. Final gene-ID counts are saved.
- A random-list serialization syntax error was fixed before random evaluations began. Main/LOPO checkpoints were reused. Auxiliary worker scripts were later amended while running; an end-of-file parse error occurred after all of their checkpoint writes. Their cached outputs were loaded successfully by the main process, all 50 complete programs were validated, and the corrected worker resumed successfully (`02c_worker_resume_validation.log`). No failed or partial activity table was accepted.
- Missing optional Python `statsmodels` and `tabulate` were handled without environment modification: BH uses SciPy `false_discovery_control`, and the report uses a simple Markdown formatter. R fgsea BH and SciPy BH were cross-checked numerically.
- Official `get_weighted_ligand_target_links(..., n=250)` can return NA target placeholders when no top250 target intersects the program. These are retained in raw links and explicitly labeled in integration; missing targets are not invented or plotted as zero weights.
- Benign R messages about unavailable system bus/time service, package method masking, and the ggplot2 errorbarh deprecation do not change computed results. Package session information is saved. Original thresholds, frozen signatures, background, and ligands were never optimized in response to results.
